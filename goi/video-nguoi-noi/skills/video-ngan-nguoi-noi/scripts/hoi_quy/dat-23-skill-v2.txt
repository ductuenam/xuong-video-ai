Anh chị cài cả chục skill mà Claude chẳng bao giờ gọi tới? Lỗi không nằm ở file đâu. Hiểu skill chạy thế nào bên trong là sửa được ngay nên mình mổ xẻ trong bốn phần nhé!
Phần một là skill gồm những gì. Tối thiểu chỉ cần một thư mục có một file skill chấm M D. Đầu file là tên và dòng mô tả nói skill làm gì và khi nào dùng. Bên dưới là các bước làm việc. Skill lớn hơn thì thêm file tài liệu tra cứu với file mẫu và thư mục scripts chứa code chạy sẵn.
Phần hai là Claude nạp skill thế nào. Lúc mở lên nó chỉ đọc tên và mô tả của mọi skill, mỗi cái chừng một trăm token nên cài cả chục skill vẫn nhẹ. Khi anh chị nhờ việc khớp với một mô tả thì Claude mới mở file skill chấm M D của đúng skill đó. Tài liệu kèm theo thì cần file nào mới mở file đó, còn script thì chạy luôn và chỉ lấy kết quả.
Phần ba là một ví dụ chạy thật. Mình có skill báo giá nội thất và anh chị gõ báo giá tủ bếp dài ba mét. Claude dò danh sách thấy mô tả báo giá khớp nên mở skill chấm M D. Bước một bảo tra bảng giá thì nó mở đúng file bảng giá. Bước hai bảo tính tiền thì nó chạy script tính giá và chỉ nhận về con số. Còn file hợp đồng mẫu không liên quan thì không hề mở. Tóm lại là bốn bước tìm, chọn, nạp rồi làm.
Phần bốn là ba điều hay hiểu sai. Thứ nhất skill không dạy lại mô hình mà chỉ đưa đúng tài liệu vào đúng lúc. Thứ hai skill khác Em‑Xi‑Pi vì Em‑Xi‑Pi nối Claude với dữ liệu và công cụ còn skill dạy Claude làm gì với dữ liệu đó, hai cái dùng chung được. Thứ ba file skill chấm M D không có phép thuật, mô tả mơ hồ thì Claude không bao giờ gọi tới. Và nhớ chỉ cài skill từ nguồn tin cậy vì skill có thể chứa code chạy trên máy.
Skill là tính năng có sẵn của Claude, viết đúng là dùng được ngay. Skill của anh chị đã viết mô tả kỹ chưa? Mẫu viết skill đầy đủ mình để sẵn ở bình luận ghim nhé!
